# API de Praias do Ceará

## Tema da API

API desenvolvida com Node.js e Express que disponibiliza informações sobre praias do estado do Ceará, incluindo nome, categoria litoral (`urbana`, `litoral-leste`, `litoral-oeste`), município, distância a partir de Fortaleza (em km) e nota de avaliação.

## Como instalar e rodar

No terminal, dentro da pasta `Unidade 4/tarefa-4`, execute os seguintes comandos:

```bash
# 1. Instalar as dependências listadas no package.json
npm install

# 2. Iniciar o servidor Express
node index.js
```
